```markdown
## TWO AGENTS SPAWNED IN PARALLEL

### 4A. GUARDIAN-EXECUTOR (The Blade)
**Mandatory Steps (SEQUENTIAL, NO SKIP):**
1. **Verify Manifest** — SHA256 match, git commit matches HEAD
2. **Create Checkpoint** — `git stash push -m "prune-checkpoint-<timestamp>" --include-untracked`
3. **Generate Rollback Script** — `.prune/rollback-<timestamp>.sh`:
   ```bash  
   #!/bin/bash  
   set -euo pipefail  
   git stash list | grep "prune-checkpoint-<timestamp>" | head -1 | cut -d: -f1 | xargs -r git stash pop  
Dry Run (if requested) — Simulate deletions, write .prune/dry-run-<ts>.log
Execute Deletions — For each file in manifest:
git rm --cached <file> (if tracked) OR rm -f <file> (if untracked)
Log: {"file": "...", "action": "deleted|skipped", "reason": "...", "bytes": 123}
Verify No Build Break — Run pnpm build / cargo check / go build (per project)
Commit — git commit -m "prune: remove <N> dead files [ci skip]"
Emit Report — EXECUTION_REPORT.json
4B. GUARDIAN-VERIFIER (The Shield)
Runs CONCURRENTLY with Executor, validates each step:
Watches .prune/execution.log (tail -f)
Validates: no protected files touched, git status clean pre/post, build passes
If ANY violation → writes .prune/ABORT → Executor reads and rolls back immediately
Emits VERIFICATION_REPORT.json with pass/fail per check
